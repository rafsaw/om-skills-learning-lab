0a. Lesson 2 deep dive — how config selects behavior

Wizualne utrwalenie najważniejszej myśli z Lesson 2: config wybiera, a deskryptory implementują.

  • browser: agent-browser

  • labels.pipeline
  • qaGate: false

Selects

  • which browser implementation to use

Rule of thumb: deskryptor mówi jak wykonać daną klasę operacji, a agentic.config.json mówi którego deskryptora i jakich zasad używać w tym repo.

1. Big Picture — system, nie pojedynczy agent

Skills działają na wspólnym stanie repozytorium i trackera. To on pozwala kolejnym etapom przejmować pracę.

Findings 003–004
Architecture mental model

Repository knowledge

  • AGENTS.md — orientation + task routing
  • SDLC.md — delivery process
  • .ai/agentic.config.json — pipeline config
  • CODE_REVIEW.md / BACKWARD_COMPATIBILITY.md
  • .ai/trackers/github.md — tracker operations

Najbardziej widoczna pętla Lesson 4. Review może zmienić stan PR, naprawić findings i uruchomić kolejną recenzję.

8. Learning Pattern — how we add new skills

Nie instalujemy całej kolekcji na zapas. Każdy nowy skill wchodzi do mapy dopiero po świadomym poznaniu.

lab rule
1 · installZainstaluj tylko skill potrzebny w bieżącym flow.
2 · inspectPrzeczytaj SKILL.md i sprawdź companion skills / dependencies.
3 · runUruchom go na realnym issue, branchu lub PR.
4 · observePatrz na GitHub, branch state, worktrees, labels i output.
